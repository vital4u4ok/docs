Meridian Bank is not a real bank. Every hostname, IBAN and card number here is fictional, and
nothing you send from the playground reaches a real service.

The description is the point. `openapi.yaml` covers as much of the OpenAPI Specification as a
single readable document can: every security scheme type, every parameter serialization style,
deprecation at every level the specification allows, and the parts of JSON Schema 2020-12 that
matter in practice.

## What the API covers

| Resource | What you can do |
| --- | --- |
| Accounts | Open, read, amend and close accounts. Cursor pagination, conditional requests, merge and JSON patch. |
| Transactions | Read postings, move money across four payment rails, stream an export. |
| Payments | Read payment instructions and place or release holds on them. |
| Cards | Read card instruments, as JSON or as XML. |
| Documents | Upload KYC documents, one at a time or as a batch. |
| Reference data | Look up ATMs and FX prices without authenticating. |
