The Pet Store API lets you manage pets in your store. All requests use JSON and require bearer token authentication.

## Base URL

```text
https://api.example.com/v1
```

## Authentication

Pass your API token in the `Authorization` header on every request:

```bash
curl https://api.example.com/v1/pets \
  -H "Authorization: Bearer YOUR_TOKEN"
```
